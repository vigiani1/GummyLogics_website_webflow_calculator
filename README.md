# GummyLogics Calculator

Standalone HTML calculator for melt-base gummy batch planning.

- File: `index.html` (this repo).
- Open locally or host on GitHub Pages / Cloudflare Pages, then iframe into Webflow `/calculators`.
- Client-side only. Saved batches use browser localStorage.
- Do not commit Stripe or other secret keys.

21+ planning tool. This project does not sell THC or CBD products.
